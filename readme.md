# E-commerce Product Page

A product detail page built with **HTML** and **CSS Flexbox**. It shows product images, description, pricing and purchase options, and adjusts to different screen sizes.

## Project Objective

To enable students to design an e-commerce product page using HTML and CSS, with Flexbox used for layout and alignment.

## Problem Description

Create a product detail page that displays:

- Product images
- Product description
- Pricing
- Purchase options

---

## Required Steps

1. Create HTML structure
2. Add product images
3. Add product details
4. Use Flexbox for layout
5. Style the pricing section
6. Add buttons and UI elements
7. Improve spacing
8. Make the page responsive
9. Test the UI
10. Push to Git
